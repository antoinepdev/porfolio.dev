# Portfolio — Antoine Peña Amores

Personal portfolio and professional card for **Antoine Peña Amores**, a
fullstack developer from Cuba specialized in backend development.

Built with **Astro**, **Tailwind CSS** and **TypeScript**.

## Features

- Landing page with hero, skills, projects, about and blog sections
- Blog with written articles and infographic posts
- Light/dark theme toggle
- SEO meta tags, Open Graph and JSON-LD structured data

## Technologies

- [Astro](https://astro.build/)
- [Tailwind CSS](https://tailwindcss.com/)
- [TypeScript](https://www.typescriptlang.org/)
- [Bun](https://bun.sh/)

## Development

```bash
bun install
bun run dev      # start dev server
bun run build    # build for production
bun run preview  # preview production build
```
